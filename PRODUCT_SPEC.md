# AgentPilot AI — Product Specification

## 1. Product Experience

AgentPilot AI should provide a simple and fast experience for online store owners.

The user should understand the main purpose of the platform within a few seconds.

The interface should prioritize:

- Simplicity
- Clarity
- Speed
- Mobile usability
- Minimal visual clutter

The product should follow the principle:

> Simple by default, powerful when needed.

---

## 2. Main Navigation

The initial product experience contains two primary pages:

1. Global Leaders
2. Profit Calculator

The user should be able to move between these pages with a single tap.

---

# 3. Page One — Global Leaders

## Purpose

The Global Leaders page is the main landing/dashboard page.

Its purpose is to create a simple competitive experience between participating online stores.

The system displays one leading store from each supported geographic region.

---

## 4. Leaderboard Regions

The initial regions are:

- North America
- South America
- Europe
- Africa
- Asia
- Australia & Oceania

The wording "Australia & Oceania" should be used in the user interface to make the region easier to understand.

---

## 5. Ranking Logic

The leaderboard compares participating stores across supported commerce platforms.

The competition is not separated by platform.

For example:

A Shopify store can compete against an Amazon store if both stores belong to the same geographic region.

The primary ranking metric is:

**Units sold during the last 24 hours.**

The store with the highest eligible number of units sold becomes the regional leader.

---

## 6. Leader Card

Each regional leader should have a simple visual card.

The card should display:

- Rank
- Medal where applicable
- Store name
- Optional owner display name
- Commerce platform
- Geographic region
- Product name
- Product price
- Units sold during the last 24 hours

Example:

🥇 Trend Store

North America  
Shopify

Product: Wireless Pro  
Price: $49  
Sold: 472 units

The interface should avoid displaying unnecessary information.

---

## 7. Medal System

The system should visually distinguish the top three positions.

### First

🥇 Gold

### Second

🥈 Silver

### Third

🥉 Bronze

The visual treatment should remain elegant and simple.

---

## 8. Public Store Identity

Store owners should control how their store appears publicly.

Recommended public information:

- Store name
- Optional display name
- Country or region
- Commerce platform

The system must not publicly display:

- Email addresses
- Private store information
- Sensitive business data
- Private customer information

---

# 9. Leaderboard Filters

The initial interface should remain simple.

Possible filters:

### Region

- All
- North America
- South America
- Europe
- Africa
- Asia
- Australia & Oceania

### Platform

- All
- Shopify
- Amazon
- Other supported platforms

Filters should not overwhelm the main interface.

---

# 10. Time Period

The primary leaderboard period is:

**Last 24 Hours**

The interface should clearly communicate that the ranking is based on the latest 24-hour period.

Future options may include:

- 7 Days
- 30 Days
- Historical

These are not required for the initial MVP.

---

# 11. Profit Calculator Page

The Profit Calculator is a completely independent page.

It should not be embedded inside the leaderboard.

The user reaches it by tapping:

**🧮 Profit Calculator**

---

## 12. Calculator Design

The calculator should be extremely simple by default.

Basic inputs:

- Selling price
- Product cost
- Advertising cost
- Shipping cost

Primary action:

**Calculate Profit**

---

## 13. Calculator Results

After calculation, the user should immediately see:

### Net Profit

Example:

$22

### Profit Margin

Example:

44%

The results should be visually prominent.

---

## 14. Advanced Calculator

Advanced costs should remain hidden by default.

Users may optionally open:

**Advanced Costs**

Possible advanced inputs:

- Platform fees
- Payment processing fees
- Taxes
- Other expenses

This prevents the calculator from becoming complicated for beginners.

---

# 15. Free Experience

The free experience should allow users to:

- View the leaderboard
- Use the basic profit calculator
- Access limited AI functionality
- Explore basic store insights

Advertising may be displayed to free users.

---

# 16. Paid Experience

The paid experience should provide meaningful additional value.

Potential features:

- Ad-free experience
- Advanced analytics
- Advanced profit analysis
- Store comparison
- Competitor insights
- Advanced AI assistance
- Historical data
- Alerts
- Multiple store connections
- Advanced reports

---

# 17. AI Experience

The AI assistant should not overwhelm users.

The interface should allow users to ask simple questions about their store.

Examples:

- "Why did my profit decrease?"
- "Which product is performing best?"
- "How can I improve my margin?"
- "What should I focus on this week?"

The AI should provide concise and actionable answers.

---

# 18. User Journey

The initial user journey should be:

1. User enters AgentPilot.
2. User sees the Global Leaders.
3. User explores the regional leaders.
4. User notices product prices and sales.
5. User can open the Profit Calculator.
6. User calculates potential profit.
7. User can explore AgentPilot AI.
8. User may create an account.
9. User may connect a store.
10. User may upgrade to a paid plan.

The journey should remain simple.

---

# 19. Mobile Experience

The product must be designed for mobile devices from the beginning.

Important requirements:

- Large touch targets
- Simple navigation
- Readable typography
- Responsive cards
- Minimal scrolling where possible
- Fast loading
- No unnecessary interface elements

---

# 20. Design Philosophy

AgentPilot should feel:

- Modern
- Professional
- Simple
- Trustworthy
- Competitive
- Intelligent

The interface should avoid:

- Excessive charts
- Excessive numbers
- Complex dashboards
- Unnecessary animations
- Technical terminology
- Information overload

---

# 21. MVP Scope

The first version should focus on:

1. Global Leaders page
2. Regional leader cards
3. Product price
4. Units sold
5. Medal system
6. Independent Profit Calculator
7. Basic navigation
8. Mobile-first interface
9. Basic account architecture
10. Foundation for store connections

Advanced analytics and AI features can be expanded after the core product is stable.

---

# 22. Long-Term Product Direction

AgentPilot should evolve from a simple leaderboard and calculator into an intelligent commerce platform.

Long-term experience:

Global Leaders
→ Profit Calculator
→ Store Analytics
→ AI Assistant
→ Competitor Intelligence
→ Automated Recommendations

The product should become more powerful without becoming more complicated for the user.
